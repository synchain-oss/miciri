# Synchain Miciri

> An open-source plugin that checks your vocal recording setup: gain, distance, mic direction, room and noise.

**Miciri** (pronounced *MIC-i-ri*; Chinese name 见切, "judging the distance") is for people who are new to recording vocals. It walks you through a few short tests, then tells you the one thing worth changing first and shows the numbers behind it. Audio passes through unchanged.

> **Status: in development.** There is no release yet. Work happens on the `feature/v1` branch.

Planned formats: VST3 on Windows and macOS, Audio Unit on macOS.
