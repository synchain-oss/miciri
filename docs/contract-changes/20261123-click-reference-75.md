# 口水音的参考值改为每分钟 75 次（桥版本不变）

接着 `20261122-click-reference.md`。口水音的读数改成不随分析起点变化之后（预测系数逐样本插值，局部尺度与语音电平用互相重叠的块），
同一批录音的读数整体略有上移，参考值随之从每分钟 60 次改为 75 次。依据只看聚合结果：两位说话人在约 15 cm 处的自然读数都低于它，
一位刻意咂嘴时高于它，另一位刻意咂嘴时与正常读数相近；检出里仍有送气音（t、k）的误报，所以这仍只是参考，不是档界。
口水音照旧不分档，也不进“最该改”。

| 项 | 以前 | 现在 |
|---|---|---|
| `thresholds.json` 的 `click.reference_max_per_min` | `60`（`pending`，经验值） | `75`（`pending`，经验值） |
| 快照 `bands.clickReferencePerMin` | `60` | `75` |
| `RESULT.md` 里口水音的参考 | 每分钟 60 次以下 | 每分钟 75 次以下 |

字段、名表与建议键都没有变，`BRIDGE_API_VERSION` 仍是 2。`overReference` 与 `advice.click` 的规则不变，只是比较的数变了。

界面要做的事：没有。口水音卡上的参考值从快照读，用户指南的中英文两份已同步。
