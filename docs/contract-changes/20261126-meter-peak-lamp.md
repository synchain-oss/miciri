# 电平事件：峰值改为真峰值，削波灯改为 5 秒自动熄灭（桥版本不变）

`miciri.meters` 的字段名、名表和桥版本都没有变，变的是三个字段的取值口径。

| 字段 | 以前 | 现在 |
|---|---|---|
| `peakDbfsL`、`peakDbfsR` | 两次读取之间的样本峰值 | 两次读取之间的真峰值：4 倍插值，采样率高于 96 kHz 时 2 倍，与增益步用的是同一个插值核 |
| `levelDbfsL`、`levelDbfsR` | 最近一个音频块的均方根 | 两次读取之间整段的均方根 |
| `clipLatchL`、`clipLatchR` | 出现过削波就保持，直到用户清除 | “削波灯亮着”：最后一次削波之后 5 秒内为真，点灯清除后为假 |

`clearClipLatch` 的语义随之变成“立即熄灯”：清除之前已经发生的削波不会再把灯点亮，之后的新削波会。计时在原生一侧按墙钟做，
界面只照事件里的状态画灯。编辑器每次打开时先清一次，所以编辑器关着时发生的削波不会在重新打开时点灯。

原因：界面的液面以前画的是 `levelDbfs`（单块均方根），而刻度、读数、目标区和增益判档都按峰值，人声的峰均比让液面比峰值线低一大截。
现在液面画 `peakDbfs`，均方根只作液面里一层淡色内芯。

界面要做的事：左栏和大字模式的电平条改读 `peakDbfs`（已同提交完成）。字段仍是 `METER_FIELDS` 里的六项，旧界面读新载荷不会出错，
只是液面会按峰值画。
