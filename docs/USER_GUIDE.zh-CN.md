# Miciri 使用指南

Miciri（读作 *MIC-i-ri*，中文名见切）帮你检查人声录音的设置。它对你话筒的信号做几个简短的测试，告诉你最该先改的一件事，并给出背后的数值。
音频原样通过：Miciri 只听，不改。不录音，也不往任何地方发送，见 [PRIVACY.zh-CN.md](PRIVACY.zh-CN.md)。

## 安装

每个系统有两种下载。刚接触插件：用**安装包**。自己管理插件目录：用 **zip**。两种都没有签名，也没有公证。发布时还会附一个
`SHA256SUMS` 文件，想确认下载没有损坏，可以拿它和你下载的文件的校验值对一下。

### Windows（x64，VST3）

1. 运行 `Miciri-v<版本>-win64-setup.exe`。向导的语言跟随你的 Windows 显示语言（英文或简体中文）。安装包没有签名，Windows SmartScreen
   可能提示“未知发布者”：点“更多信息”，再点“仍要运行”。
2. 安装包把 `Miciri.vst3` 放进标准的 VST3 目录（通常是 `C:\Program Files\Common Files\VST3`），把许可文本、声明和卸载程序放进 `Program Files\Miciri`。
3. 在 DAW 里重新扫描插件。

用 zip 的话：把 zip 里的 `Miciri.vst3` 文件夹复制到 `C:\Program Files\Common Files\VST3`（需要管理员权限），然后重新扫描。

插件窗口用 Microsoft Edge WebView2 运行时绘制，新版 Windows 10 和 11 自带。缺它时，插件会显示一块说明面板，而不是正常窗口；
从微软安装 Evergreen 运行时即可。

卸载：Windows 设置 > 应用 > Miciri；用 zip 的话，删掉 `Miciri.vst3`。

### macOS（Apple 芯片，VST3 与 Audio Unit）

1. 打开 `Miciri-v<版本>-macos-arm64.pkg`，照安装程序走。VST3 装到 `/Library/Audio/Plug-Ins/VST3`，Audio Unit 装到
   `/Library/Audio/Plug-Ins/Components`。
2. **第一次打开，macOS 会拦住安装包**，因为 Miciri 没有签名和公证。这是预期的，用下面任一种办法：
   - 打开**系统设置 > 隐私与安全性**，滚到“安全性”一栏，找到说 Miciri 被拦截的那一条，点**仍要打开**（不同 macOS 版本的字样略有不同）。然后再打开一次安装包。
   - 或者先在“终端”里解除隔离，路径换成你下载的文件：
     `xattr -dr com.apple.quarantine <下载的 .pkg 的路径>`
3. 在 DAW 里重新扫描插件。如果 DAW 仍然说插件被拦截或已损坏，对装好的插件也解除一次隔离：

   ```sh
   xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/Miciri.vst3
   xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/Components/Miciri.component
   ```

用 zip 的话：把 `Miciri.vst3` 复制到 `~/Library/Audio/Plug-Ins/VST3`，把 `Miciri.component` 复制到 `~/Library/Audio/Plug-Ins/Components`
（目录不存在就先建），再按这两个路径执行上面的两条 `xattr` 命令，然后重新扫描。安装包和 zip 里的 `INSTALL.txt` 用中英文重复了这些步骤。

要卸载，删掉装进去的这些项目。macOS 的安装包没有卸载程序。

## 开始之前

- **戴耳机。** 监听打开、音箱外放时，话筒会听到音箱，测量会受影响。不得已用音箱，就把音量调低。
- **把 Miciri 放在你录人声的那条轨道上**，并确认声音能进到它里面：输入选好了，需要监听的宿主里监听也打开了。每个 DAW 的做法不同，这里不教，请看你的 DAW 自己的说明。
- 单声道和立体声轨道都可以。单声道轨上 Miciri 只显示一路电平；立体声轨上显示左右两路，并检查它们是否正常。
- 在你平时真正录音的位置测，增益和距离保持你平时的用法。Miciri 测的是它听到的东西，看不出你本来想设成什么。
- 测试时让 DAW 实时播放或监听。离线渲染时 Miciri 不做测试。

窗口一打开就是一根大的电平条。说话，电平条动了，就说明信号进来了。

## 窗口

- **左边是输入栏。** 电平表（带真峰值和目标区）、缓冲大小、一盏点一下就清除的削波灯，以及话筒类型（动圈、电容、USB 话筒、耳机麦或不确定，可以跳过）。
  测完之后，电平表上还会出现底噪、电流声和最响一次口水音的标记；鼠标放上去能看到它是什么。
- **顶部的步骤条：** 接通、增益、安静、房间、位置、方向（进阶）和报告。每一步标着未做、当前、完成、已过期或失败。点步骤、点露出来的上一张或下一张卡、
  点“下一步”都能翻页，滚轮也行。
- **角落的按钮：** 语言（英文或简体中文）、窗口缩放、打开应用内指南的“?”按钮，还有“关于”。缩放要你确认，不确认的话约 10 秒后自己退回。

测试进行时，窗口只显示一句大字指令和一整块颜色，表示开始、成功和“重来”，让你在唱歌的位置也读得清。

## 每一步怎么做

每一步都很短。开始前窗口会写“约 N 秒”，进行中有计数。颜色跟着结果走：绿色是合格或有信号，琥珀是值得注意，红色是先改这个，灰色是没测或已过期，紫色是当前或下一步。

### 1. 接通

如果知道话筒类型就选一下（也可以跳过），然后说话。电平条动了，就按开始。这一步还会报告采样率和缓冲大小；立体声轨上还会看左右两路是不是都有声音。
哪里不对，卡片会写可能是什么原因，见[收不到信号时](#收不到信号时)。

### 2. 增益（约 8 秒）

用你录音时最大的音量唱，一直唱到这一步结束。Miciri 读峰值电平（真峰值）和有没有削波。目标区画在电平表上。削波了，就把输入音量调低一大截再测；
离目标区很远偏低，就调高一些。Miciri 不会告诉你该拧哪个旋钮，因为它读不到你的硬件：USB 话筒调的是系统的输入音量。

### 3. 安静（约 8 秒）

保持安静，别动。Miciri 量底噪（用相对你唱歌电平的信噪比表示），并查有没有电流声。听到说话声或碰撞声，这一步会自己重新开始。
它还会找设备在处理声音的迹象（噪声门、很重的降噪），这些会让别的结果看起来比房间的实际情况好。

### 4. 房间（约 20 秒）

站在离话筒约 1 米的地方，用力拍手。每一下都有反馈，卡片会数还差几下。要凑够 4 下有效的，最多收 8 下；被搅了的一组会标“作废”。
Miciri 从每一下拍手的衰减里估计房间的回声持续多久（T20），分四个频段。这一步就是要用力拍，所以拍得响没关系。
如果卡片说设备可能开了降噪或噪声门，关掉后再拍一遍。

### 5. 位置（约 1 分钟）

回到你唱歌的位置，保持你平时的距离。

1. 轻拍 3 次。
2. 把第一张字表念两遍，一字一顿，用唱歌的力度，不用跟节拍。例如“怕 跑 拍 炮 / 他 踢 开 哭”。
3. 把第二张字表也念两遍。例如“四 三 丝 / 书 西 七”。
4. 像平时说话一样念一小段。

字表不用背，Miciri 也不判断你念得对不对。它量的是话筒听到的声音里，直达的人声和房间声各占多少（D/R）、喷麦（p、t、k 的爆破气流）、齿音（s、sh 的嘶声）和口水音。
这些合起来给出太近太远的标尺。某一遍的音量明显低于增益那一步时，Miciri 会请你重念。

### 6. 方向（可选，约 25 秒）

朝话筒的四个方向各念几秒。Miciri 只回答一个问题：当前方向是不是最响最亮的那个？如果别的方向明显更响，它会把那一对再测一次确认，
两次都成立，才说话筒可能放反了。它不猜你的话筒型号。话筒类型选了“耳机麦”，这一步就隐藏。
没测方向，不会妨碍报告最后说“可以开始录音了”。

## 报告与重测

报告第一屏是**最该先改的一件事**，加上一到三个具体动作。下面是各项结果卡，每张只显示一个词和一个主数字；点开一张卡看详情（读数、比值和背后的证据）。

- **只重测你改过的。** 报告里有“做了改动？”，三个按钮：*我调了增益*、*我挪了位置*、*我换了房间*。点了以后受影响的卡标成已过期，再点一下只重测这几项。
- **上次 → 现在。** 每张卡保留上一次的数值，让你看改动有没有用。一个问题解决了，下一个顶上来，最后报告会说可以开始录音了。
- **复制结果**把一句话总结放进剪贴板，方便你贴到消息或论坛里。
- 卡片已过期，是说它的测量不再适用了，比如采样率变了，或你挪了话筒。

## 收不到信号时

Miciri 读不到 DAW 里的监听和 arm 状态，所以下面这些提示一律写“可能”。

| 接通卡看到的情况 | 可能的意思 |
|---|---|
| 约 2 秒没有音频回调 | 可能没开监听，或插件被休眠或旁路了 |
| 有音频，但从一开始就严格全是零 | 可能没开监听、轨道没 arm 或输入选错了 |
| 之前有信号，之后严格全是零 | 声音可能被静音了、噪声门可能关上了，或宿主停了 |
| 极低的噪声，说话也不上升 | 通路是通的，但话筒可能没连好、幻象电源可能没开，或增益可能是零 |
| 立体声轨上只有一路有声音 | 录出来可能只在一边：改用单声道轨，或检查输入 |
| 两路相位相反 | 两路是同一个声音，但一路是反的，合成单声道时可能抵消。检查话筒线和接口上的相位开关 |

其中有些情况和“房间很安静、没人说话”在信号上分不开，所以主按钮始终可以点。

## 词汇表

- **dBFS**：相对数字满刻度的分贝。0 dBFS 是数字信号能装下的最大电平，更小的电平是负数。
- **峰值 / 真峰值（dBTP）**：信号的最高电平。真峰值还能抓到落在采样点之间的峰。
- **削波**：信号撞到天花板被削平。听起来刺耳，事后修不回来。
- **增益**：输入被放大多少。太低，人声会淹在噪声里；太高，会削波。
- **底噪 / 信噪比**：一直存在的背景噪声，以及你的人声比它高多少。信噪比越大越好。
- **电流声**：电网频率（50 或 60 Hz）上的稳定低音，连同它的谐波，多半来自接线或电源。
- **T20（混响时间）**：房间里一个声音消散要多久的估计，取自拍手之后最先下降的 20 dB。越长，房间越空、回声越明显。
- **D/R（直达声与房间声比）**：在你的位置上，直达的人声比房间反射声响多少。低，说明录进去的房间声多。
- **喷麦**：p、t、k 的气流冲击话筒，发出低频的“噗”声。
- **齿音**：s、sh 的尖锐嘶声。太多听起来刺耳。
- **口水音**：嘴里发出的细小咔哒声和湿润的声音。离话筒很近时通常更重。
- **动圈话筒 / 电容话筒**：动圈话筒皮实，需要更多增益；电容话筒更灵敏，需要接口提供幻象电源。USB 话筒把接口做在了里面。
- **相位**：波形的时间位置。两路相位相反，加成单声道时会互相抵消。
- **已过期**：不再对应你当前设置的结果，需要重新测。

## 常见问题

**Miciri 会改我的声音吗？**
不会。音频逐位直通。Miciri 只分析收到的音频的一份拷贝，从不静音、滤波或处理信号。

**它会录我的声音或把它发到别处吗？**
不会。音频边收边在内存里分析，不保留。插件不发任何网络请求。见 [PRIVACY.zh-CN.md](PRIVACY.zh-CN.md)。

**macOS 为什么说插件无法打开，或者说它已损坏？**
macOS 版的 Miciri 没有签名和公证，Gatekeeper 会拦下载来的文件。照[安装](#安装)里的步骤，允许安装包，再对装好的插件解除隔离。

**电平条不动，怎么办？**
先确认戴了耳机、这条轨道的输入选好了、需要监听的宿主里监听开了、插件没有被旁路。然后看[收不到信号时](#收不到信号时)。Miciri 看不到那些 DAW 设置，所以只能说“可能”。

**它能在我的 DAW 里用吗？**
能加载 VST3（Windows、macOS）或 Audio Unit（macOS）的宿主都可以尝试加载，但目前没有任何宿主有完整的测试记录。兼容表在
[KNOWN_ISSUES.md](KNOWN_ISSUES.md)，没测过的宿主都写着“未测”。

**这一步自己重新开始了，是 bug 吗？**
不是。有东西搅了这一步，它就会重来：安静步骤里的说话声或碰撞声、削波的拍手、或明显比增益那一步轻的一遍。卡片会写原因。

**为什么我在渲染时它说不能测试？**
Miciri 只在实时播放或监听时测试。离线渲染时插件收到的是工程里的音频，测出来的是那段音频，不是你的话筒。已知的局限见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。

**结果有多准？**
读数是真实的测量，但“好、一般、差”之间的分界还是起始值，还没有用真实录音标定。把它当参考，最后以你的耳朵为准。
