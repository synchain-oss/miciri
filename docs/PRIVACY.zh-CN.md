# 隐私

Miciri 要听到你话筒的信号才能测量。这一页写清楚这路信号会怎样、插件会留下什么。以后只要有变化，就在同一个 PR 里改这一页。

## 一句话

- 音频只在内存里分析，**不写盘、不上传、不进日志**。
- 插件不联网：没有遥测，没有账号，不检查更新，不上传崩溃信息。
- 音频原样通过插件，逐位不变。

## 留在内存里的

- 每个测试步骤的音频边收边分析，分析完就丢，插件不录音。
- 你的测试结果（电平、比值、档位，以及详情里画证据用的内容：标出的时间、频率和电平，还有证据波形的包络）在插件加载期间放在内存里。
  关掉插件窗口不会丢，卸载插件才清除。
- 就这个版本而言，插件不往你的 DAW 工程里存任何东西。

## 写到磁盘上的

- 一个很小的用户级设置文件，放在你的用户应用数据目录下的 `Synchain/Miciri`
  （macOS 是 `~/Library/Application Support/Synchain/Miciri`）。里面只有三样：界面语言、你有没有看过应用内指南、窗口缩放。
  没有音频，也没有测量结果。
- 画插件窗口的网页视图（Windows 上是 Microsoft Edge WebView2，macOS 上是 WKWebView）会像任何浏览器一样，在你的电脑上留它自己的配置和缓存目录。
  插件只加载打包在自己里面的页面，所以那个目录里是这些页面，没有你的录音内容。

## 网络上看得到什么

插件什么都不发。窗口只加载打在插件里的本地页面；项目的 CI 里有一项检查，插件和它的页面里出现网络代码或外部地址就判红。
你点一个链接时，插件只是把地址交给系统浏览器，自己不发请求。Windows 上的 Microsoft WebView2 运行时是微软的组件，按微软自己的条款走。

## 不在发行版里的

- 宿主测试用的构建（CMake 选项 `MICIRI_HOST_PROBE`，见 [HOST_PROBE.md](HOST_PROBE.md)）可以把一小份计数的 JSON 写到环境变量指定的路径。
  它默认关闭，发行版的二进制里没有这段代码。计数只有块数和标志，没有音频。
- 命令行工具 `miciri-analyze` 读你给它的 WAV 文件，把数值打印在你的屏幕上，不上传任何东西。

## 报告问题

不要把录音附在 issue 或 PR 里。读数看起来不对时，只贴 `miciri-analyze` 导出的数值 JSON。安全问题走 [SECURITY.md](../SECURITY.md) 里的渠道。
