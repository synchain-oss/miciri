# Synchain Miciri

> 一个开源插件，帮你检查人声录音的设置：增益、距离、话筒方向、房间和噪声。

**Miciri**（读作 *MIC-i-ri*，中文名见切，意为看准距离）面向刚开始录人声的人。它带你做几个简短的测试，然后告诉你最该先改的一件事，并给出背后的数值。音频原样通过，不做任何改动。

> **状态：开发中。** 还没有发布版本。开发在 `feature/v1` 分支上进行。

计划支持的格式：Windows 和 macOS 上的 VST3，macOS 上的 Audio Unit。
